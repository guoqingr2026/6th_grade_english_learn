# Basic Vocabulary

Learning the most common words is the first step to mastering English. Here is a list of essential vocabulary.

## Greetings & Polite Words
| English | Meaning / Notes |
|---------|----------------|
| Hello / Hi | Standard greeting |
| Good morning | Used before 12:00 PM |
| Good afternoon | Used from 12:00 PM to 5:00 PM |
| Good evening | Used after 5:00 PM |
| Please | Used to make a polite request |
| Thank you / Thanks | Used to express gratitude |
| You're welcome | Standard response to "Thank you" |
| Excuse me | Used to get someone's attention or apologize politely |
| Sorry | Used to apologize |

## Question Words (The 5 Ws and 1 H)
| Word | Usage | Example |
|------|-------|---------|
| Who | Asking about a person | **Who** is that? |
| What | Asking about a thing/action | **What** is this? |
| Where | Asking about a place | **Where** are you? |
| When | Asking about time | **When** does the train leave? |
| Why | Asking for a reason | **Why** are you late? |
| How | Asking about a method/state | **How** are you? |
