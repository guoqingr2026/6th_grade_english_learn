## 一、产品说明书

### 1.1 产品定位

面向 **2026 新人教版 PEP 六年级英语上册** 的综合复习训练 Web 应用，覆盖：

- 单词闪卡、常用语、语法句型、选择题、综合填空、动词专项、作文仿写
- 全模块 **错题本**（自动收录 + 定向复习）
- **双轨积分**：做题积分 + 行为积分 → 累积积分
- 家长密码保护敏感操作
- 学习报告 / 积分台账导出
- **题库与程序分离**，支持课堂题卡批量导入
- **局域网一键同步**：PC 与手机对齐学习档案（最新修改为准）

适用场景：家庭自学、课堂局域网共学、家校共育激励。

### 1.2 核心功能一览

| 模块 | 功能说明 | 标签显示 |
|------|----------|----------|
| 单词卡片 | 中英对照、音标、例句、单元配图，可手动判对错 | 词汇总量 |
| 语法句型 | 语法点讲解 + 主谓宾连连看；**支持单元筛选** | 语法点 + 练习题数 |
| 常用语 | 遮盖式闪卡回忆；**支持单元筛选** | 语句条数 |
| 选择题 | Unit / Part A/B 闯关，错因解析；**不自动跳题** | 题库题数 |
| 综合填空 | 审核题库抽题，英文作答；**不自动跳题** | 填空题库题数 |
| 动词专项 | **附录5 不规则动词 47 个**三态填空；支持单元筛选 | **47** |
| 优秀作文 | 范文 + 仿写填空 + 评分器 | 范文篇数 |
| 附录校验 | 词汇/短语/句型覆盖统计 | 附录总条数 |
| 学习日志 | 每日学习感想（≤100 词） | 日志条数 |
| **错题本** | 全模块错题汇总；**模块 + 单元**双筛选、复习 | **错题条数（醒目标签）** |
| **课文讲读** | 左图右文中英对照，单元分页 | 弹窗学习 |
| **知识点精讲** | 左图右精讲，表格/链接/LaTeX | 弹窗学习 |

### 1.3 积分体系（最终版）

| 概念 | 说明 |
|------|------|
| **做题积分** | 系统自动判题获得；同一题首次答对才计分 |
| **行为积分** | 家长记录课堂/生活习惯奖惩；与答对/答错统计无关 |
| **累积积分** | 做题积分 + 行为积分 − 已兑换 |
| **积分兑换** | 仅扣累积积分；累积为 0 不可兑换 |

客观练习（选择题、填空、动词等）**无需家长密码**。  
手动判题、行为记分、兑换、一键重置需 **家长密码**（详见 `PARENT_GUIDE.md`）。

### 1.4 错题本机制

- 选择题 / 填空 / 动词 / 语法 / 作文等 **系统自动答错** → 自动入库
- **单词卡片**：家长点击「回答错误（记入错题本）」→ 收录当前单词
- 顶部 **「错题本」** 标签（橙红脉冲特效）位于「学习日志」之后
- 支持：模块筛选、「复习单词错题」「复习选择题错题」、清空（需家长密码）

### 1.5 交互原则（重要）

| 区域 | 自动朗读 | 自动下一题 |
|------|----------|------------|
| 单词卡片 / 语法 / 常用语 / 选择题 / 填空 / 动词 / 作文 | **否** | **否**（须手动点「下一张 / 下一题 / 下一组」） |
| 课文中英文讲读 | 仅点 **「朗读」** 后，本页逐句向下 TTS | 否（读完本页停止，不自动翻 Part） |
| 知识点精讲 | 同上 | 否 |

练习模块 **不会** 在答对/答错后自动跳转，也不会自动播放语音。

### 1.6 界面布局

- **左侧主区**：仪表盘、**课文中英文讲读** / **知识点精讲**、练习模块
- **右侧边栏**：学生昵称 → **同步数据** → 档案导出、题库导入、排行榜、行为积分、兑换记录
- **顶部标签栏**：各模块显示题库/记录数量；错题本醒目区分
- **手机端**：练习区优先；底部固定标签栏；侧边栏可折叠展开

### 1.7 部署与访问

| 方式 | 说明 |
|------|------|
| `启动.bat`（推荐） | 题卡导入 + MD 同步 + **局域网同步服务** |
| 本机访问 | `http://localhost:8080` |
| 局域网访问 | `ipconfig` 查看 IPv4，形如 `http://192.168.x.x:8080` |
| 直接打开 HTML | `file://` 模式 **无法加载 JSON 题库且无同步**，不推荐 |
| 公网静态托管 | 见 `DEPLOY.md`（GitHub Pages / OSS 等）；**无局域网同步 API** |

发布包同步：运行 `sync-release.bat` 将最新文件复制到 `release/`。

### 1.8 数据安全

- 学习进度默认存于浏览器 `localStorage`（本机）
- 局域网同步时，数据经班级服务器（`lan-sync/` 文件夹）中转，**不上传公网**
- 一键重置需 **两次家长密码** + 确认弹窗
- 题库文件为纯文本 JSON，可 Git 管理、备份、课堂共享

## 二、学生/家长使用说明书

### 2.1 首次使用（5 步）

1. 双击 **`启动.bat`**，等待浏览器自动打开
2. 右侧输入 **学生昵称** → 点击「保存昵称」
3. 按提示设置 **家长密码**（两次确认）
4. 从「单词卡片」开始练习，或进入「选择题」闯关
5. 练习后可在仪表盘查看答对/答错/积分，在「错题本」复习

### 2.2 推荐每日学习路径（20~30 分钟）

| 时段 | 内容 |
|------|------|
| 5 分钟 | 单词卡片 + 常用语闪卡 |
| 10 分钟 | 选择题闯关 + 错题本复习 |
| 5 分钟 | 综合填空（只填英文） |
| 5~10 分钟 | 作文仿写 + 评分器 |

### 2.3 各模块操作要点

**单词卡片**

- 点击卡片翻面；用「上一张 / 下一张」切换
- 家长判错：点「回答错误（记入错题本）」→ 当前单词进入错题本

**选择题**

- 按 Unit / Part 筛选；答错显示错因解析
- 「错题本复习」按钮：只练收录的选择题错题

**综合填空**

- 每次最多 5 题；`prompt` / 中文提示 / 答案已人工审核对应
- 只接受英文单词作答

**积分与兑换**

- 学生可自行练习赚 **做题积分**
- 兑换礼品：家长输入密码 → 填写项目与消耗积分 → 从 **累积积分** 扣除

**家长模式**

- 输入密码后本会话内免重复输入
- 点「退出家长模式」后，敏感操作恢复每次输密码
- 修改密码：Alt + 连点「累积积分」标题 3 次（仅家长知晓）

### 2.4 报告导出

| 按钮 | 输出 |
|------|------|
| 导出学习报告 TXT | 文本摘要 |
| 导出 HTML 总报告 | 可打印综合报告 |
| 导出积分台账 HTML | 做题/行为/兑换流水明细 |

### 2.5 标签栏数量含义

每个标签右侧数字表示该模块 **当前可用题库/记录条数**（实时更新）。  
错题本数字为 **累计错题条数**，有错题时标签带橙红脉冲特效。

## 三、多端数据同步（重点）

### 3.1 为什么需要同步？

学习积分、错题本、导入的加题等保存在 **各设备自己的浏览器** 中。  
仅刷新页面或共用同一网址，**不会**自动对齐数据。

### 3.2 按钮位置

右侧边栏 **昵称输入框正下方**：

- 按钮：**「同步数据（多端刷新）」**
- 说明：*电脑与手机打开同一局域网地址，保存昵称后点此按钮即可同步；以最新修改为准。*
- 下方显示同步记录；首次使用提示：*暂无同步记录，点上方按钮开始同步。*

### 3.3 使用步骤（3 步）

1. **电脑**运行 `启动.bat`（必须用此方式，才有同步服务）
2. **电脑与手机**打开同一地址，例如 `http://192.168.1.8:8080`（手机不能用 `localhost`）
3. 两边 **昵称相同** 并保存 → 任意一端练习后点 **「同步数据」**

### 3.4 竞争规则（最新修改为准）

| 情况 | 结果 |
|------|------|
| 本机数据时间较新 | 更新班级服务器副本 |
| 班级数据时间较新 | 自动覆盖本机 |
| 时间一致 | 不改动 |
| 首次同步 | 建立班级数据副本 |

每次同步会写入 **同步日志**（设备、时间、结果），显示在按钮下方。

### 3.5 典型场景

| 场景 | 操作 |
|------|------|
| PC 做题后，手机要看进度 | PC 点同步 → 手机点同步 |
| 手机做题后，PC 要更新 | 手机点同步 → PC 点同步 |
| 导入 CSV 加题后 | 导入端点同步 → 其他端点同步 |

### 3.6 同步范围

昵称、积分、错题本、挑战记录、兑换记录、行为日志、勋章、学习日志、**本机导入的 CSV 加题** 等完整学习档案。

### 3.7 限制说明

- 须通过 `启动.bat` 启动（内置 `scripts/lan_server.py`）
- 须同一 WiFi / 局域网
- 公网 GitHub Pages 等静态部署 **无** 此同步功能
- 同步数据文件位于项目 `lan-sync/`（按昵称命名，可备份）

## 四、课文讲读与知识点精讲

### 4.1 入口

主区按钮（无需家长密码）：

| 按钮 | 功能 |
|------|------|
| **课文中英文讲读** | 左：课本图；右：英文 + 可滚动中文译文（**无自动朗读**） |
| **知识点精讲** | 左：课本图；右：语法/词汇/表格/链接等富文本 |
| **每日复习清单** | 错题本 + 当日 Part，约 20 分钟闭环建议 |
| **Part 通关测验** | 本 Part 抽题，≥80% 解锁下一 Part |
| **考前模拟卷** | Unit 1–6 抽题计时，下载 HTML 成绩单 |

### 4.2 弹窗功能

- 顶部 **开篇 / Unit 1–6 / 附录** 切换；**Part A / B / C / Reading** 等分页
- 左侧课本图在**同一图像框内**放大/缩小/重置，放大后可**拖拽平移**（便于课堂指读）
- 多页课文支持 **‹ ›** 翻页（`pdf-page-map.json` 映射页码，与右侧句子一一对应）
- **朗读**（讲读 / 精讲）：点击后 TTS **逐句向下**播放本页；再点变为「停止」。**不会**自动翻 Part 或进入练习下一题。
- **无「自动朗读」、无点击句子点播**（避免误触）；练习区一律手动切换。
- **A+/A−** 字号 · **护眼** 深色背景
- 精讲页：**从 Word 刷新精讲**、**从网页导入精讲**（提取网页正文更新当前页）
- 底部 **我的交互笔记**（精讲页；纳入「同步数据」多端共享）

### 4.3 课本图片（无需 PDF 转图）

图片已放在 `assets/images/textbook/pages/page-001.png` … `page-098.png`。  
**不必**再运行 PDF/OCR；若自行下载课本扫描图，按三位页码命名后放入该目录即可。

`启动.bat` 会自动：① 导入 `word-sources/` 下 CSV ② `build-study-hub.py` ③ 校验图片映射（缺图仅警告，不阻止启动）。

页码与单元 Part 的对应关系在 `data/study-hub/pdf-page-map.json` 中维护（**课本印刷页码** 与 **图册 page-XXX.png** 的映射）。

### 4.4 用 CSV 维护课文（推荐）

在 `word-sources/` 放置或编辑：

`Unit1_课文双语.csv` … `Unit6_课文双语.csv`（Word 内容请先在 Excel 中另存为 CSV）

**CSV 格式** — 第一行可为表头，也可省略（按列顺序：页码,英文,中文）：

```
page,en,zh
2,Unit 1 Amazing landmarks,第一单元 壮美的地标
4,Zhang Peng: Hi Peter! How was your weekend?,张鹏：嗨，彼得！你周末过得怎么样？
```

也可无表头，直接三列数据：

```
4,What famous landmarks do you know?,你知道哪些著名的地标？
4,Let's talk.,说一说。
```

| 您写的页码 | 左侧图片（Unit 1） | 位置 |
|-----------|------------------|------|
| Page 2 | page-009.png | 单元起始 |
| Page 3 | page-010.png | 导入活动 |
| Page 4–5 | page-011/012 | Part A |
| Page 6–9 | page-013–016 | Part B |
| Page 10–11 | page-017/018 | Part C |
| Page 12–13 | page-019/020 | Reading |

**讲读页右侧**：可滚动编辑框，**保存本页** 写入 `data/study-hub/library/reading/`；**导入 CSV** 批量转为 HTML。界面只显示 **Page N**（课本印刷页 = 图册页码 − 7，如 page-037 → Page 30）。无 HTML 文件时使用 `reading-bank.json` 默认内容；精讲同理（`library/knowledge/`）。

**更新流程**：编辑 CSV → 保存到 `word-sources/` → **双击 `启动.bat`**（自动 CSV→HTML）；或在讲读页 **导入 CSV** / **保存本页**。

也可直接编辑 `data/study-hub/reading-bank.json` / `knowledge-bank.json`（高级）。

| 文件 | 用途 |
|------|------|
| `word-import.json` | Word 导入中间结果（自动生成） |
| `reading-bank.json` | 中英讲读（按页 `pageContents` 与图片对应） |
| `knowledge-bank.json` | 精讲（`bodyHtml`） |
| `glossary.json` | 附录词汇高亮（Part A/B） |
| `pdf-page-map.json` | Unit × Part → 课本页码 |

### 4.5 富文本规范（UTF-8）

- HTML 实体：`&rsquo;` `&#128218;`
- Unicode 音标：直接书写或实体
- 表格：`<table class="rich-table">`
- 链接：`<a href="..." target="_blank" rel="noopener">`
- LaTeX：`<span class="math-inline" data-tex="x^2">` 或 `<p class="math-block" data-tex="...">`
- 引用块：`<blockquote class="ref-note">`

### 4.6 冲满分一体化

| 模块 | 说明 |
|------|------|
| 每日复习清单 | 汇总错题本 + 当前未通关 Part，建议 20 分钟学习顺序 |
| Part 通关测验 | 按所选 Unit/Part 抽题；正确率 ≥80% 解锁下一 Part（A→B→C→Reading） |
| 听读跟读 | 讲读/精讲页点 **「朗读」** → 浏览器 TTS 逐句向下（仅本页） |
| 精讲笔记同步 | `study_hub_notes_v1`、通关进度 `english_grade6_mastery_v1` 随「同步数据」合并 |
| 考前模拟卷 | 全册抽题，结束后下载 HTML 成绩单 |

## 五、题库自主更新与题卡导入（重点）

### 5.1 架构原则

```
题卡包 JSON ──导入──┐
页面 CSV 导入 ──────┤
                     ├──> *-bank.json ──fetch──> 网页练习
Markdown bank-json ──同步──┘
```

- **网页只读取** `data/question-banks/*.json`
- **Markdown（.md）**：人工阅读、AI 审核、版本对照
- **题卡包（import-cards/*.json）**：课堂加题、批量导入
- **页面 CSV**：家长日常加题（最简单）
- **`启动.bat`** 启动前自动：① 导入题卡 ② 同步 MD ③ 启动服务

### 5.2 三种更新方式对比

| 方式 | 适合场景 | 操作 |
|------|----------|------|
| **A. 页面导入 CSV（最推荐）** | 家长/老师日常加题 | 下载模板 → Excel 填写 → 导入 → **点同步** |
| **B. 题卡 JSON 导入** | 批量、AI 生成 | 放入 `import-cards/` → 运行 `启动.bat` |
| **C. 直接改 JSON / MD** | 高级维护 | 编辑 `*-bank.json` 或 `.md` 的 `bank-json` |

> **首次打开**：自动加载默认题库。CSV 导入的加题存于本机，**需点「同步数据」** 才能在多设备共享。

### 5.3 页面导入 CSV（傻瓜三步）

1. 右侧点击 **「1. 下载模板 CSV」**
2. 用 Excel / WPS 打开，按示例填写（每行一题，`type` 填 `quiz` / `fillblank` / `writing`）
3. 另存为 **CSV**，点击 **「2. 选择文件并导入」** → 其他设备 **点同步**

**表头（勿删改列名）：**

```
type,id,unit,part,itemType,prompt,answer,clue,options,badge,explain,title,en,zh,fillPrompt
```

| 列名 | 选择题 | 填空 | 作文 |
|------|--------|------|------|
| type | quiz | fillblank | writing |
| id | 唯一编号 | 唯一编号 | 唯一编号 |
| unit | 1~6 | 1~6 | 1~6 |
| part | A/B | A/B | 可空 |
| prompt | 题干 | 含 ___ 的句子 | 可空 |
| answer | 正确选项全文 | 英文答案 | 填空答案 |
| clue | 可空 | 中文提示 | 可空 |
| options | 用 `|` 分隔四个选项 | 可空 | 可空 |
| title / en / zh / fillPrompt | 可空 | 可空 | 范文标题/英文/中文/填空句 |

清除导入加题：点「清除导入加题」（需家长密码）。

### 5.4 AI 提示词（生成 CSV 行）

将以下内容复制给 AI，替换 `{单元}` `{题量}` `{主题}`：

```
你是 PEP 六年级英语上册命题老师。请按以下 CSV 表头输出题目，每行一题，不要 Markdown 表格：

type,id,unit,part,itemType,prompt,answer,clue,options,badge,explain,title,en,zh,fillPrompt

要求：
- 单元：{单元}（1~6）
- 题量：选择题 {n1} 道、填空 {n2} 道、作文范文 {n3} 篇
- 主题：{主题}
- id 格式：u{单元}-custom-01 递增，全文件唯一
- 选择题：options 用 | 分隔 4 项，answer 必须与某一 options 完全一致
- 填空：prompt 用 ___ 表示空，answer 为英文单词，clue 中文与 prompt 语义一致
- 作文：fillPrompt 为带 ___ 的英文句，fillAnswer 为填空答案；en/zh 为完整范文
- explain 写简短解析
- 只输出 CSV 正文，含表头，不要代码块标记
```

### 5.5 AI 提示词（生成题卡 JSON 包）

```

{
  "cardType": "quiz",
  "action": "append",
  "source": "来源说明",
  "items": [ ... ]
}

cardType 取值：quiz | fillblank | writing
action 固定 append（除非我要求 replace）
items 中每题 id 唯一。

选择题单题字段：id, unit, part, badge, prompt, options[], answer, explainCorrect, optionReasons{}
填空单题字段：id, unit, part, type, prompt, clue, answer, analysis
作文单题字段：id, unit, title, en, zh, fillPrompt, fillAnswer

命题要求：Unit {单元}，{题量} 题，{主题}。prompt/clue/answer 语义一致。
只输出合法 JSON，不要注释。
```

参考模板：`data/question-banks/import-cards/_templates/`

### 5.6 题卡 JSON 导入（进阶）

1. 复制 `_templates/` 示例到 `import-cards/`
2. 重命名，如 `quiz-unit3-class.json`
3. 编辑 `items`，每题 `id` 唯一
4. 双击 **`启动.bat`** → 成功包移至 `import-cards/done/`
5. 浏览器刷新；多设备需 **点同步**

```
````

- 选择题 / 填空：`questions` 数组

## 九、常见问题 Q&A

**Q：改了题库网页没变化？**  
A：是否通过 `启动.bat` 访问？是否 `Ctrl+F5` 强制刷新？CSV 导入是否在本机且已同步到其他端？

**Q：PC 改了数据，手机刷新为什么没变？**  
A：数据在本机浏览器。须同一局域网地址 + 相同昵称 + 点 **「同步数据」**。

**Q：同步失败怎么办？**  
A：① 必须用 `启动.bat` 启动 ② 手机地址用 `http://192.168.x.x:8080` ③ 同一 WiFi ④ Windows 防火墙允许 Python 专用网络。

**Q：两端同时改了数据怎么办？**  
A：以 **数据时间较新** 的一方为准（最后练习/保存的一方通常获胜）。

**Q：同步记录在哪里？**  
A：按钮下方列表；服务器端 `lan-sync/{昵称}-logs.json`。

**Q：公网 GitHub Pages 能同步吗？**  
A：不能。公网仅为静态网页；多设备同步需局域网 `启动.bat`。

**Q：题卡导入失败？**  
A：检查 JSON 格式、`cardType`、`items` 非空、每题唯一 `id`。看命令行报错。

**Q：学生能改积分/兑换吗？**  
A：不能。需家长密码。

**Q：同一题反复做还加分吗？**  
A：系统自动判题：该题 **首次答对** 后不再加做题积分。

**Q：行为积分影响正确率吗？**  
A：不影响。只影响累积积分。

**Q：课文讲读图片不显示？**  
A：将课本扫描图放入 `assets/images/textbook/`，或依赖 `fallbackImage` 单元主题图；须通过 `启动.bat` 访问。

**Q：如何更新知识点精讲？**  
A：编辑 `word-sources/UnitN_课文词汇重点句型_双语学习资料.docx` 中 `=== knowledge-part-x ===` 段落，保存后点 **从 Word 刷新精讲**；或在精讲页点 **从网页导入精讲** 粘贴链接；也可直接改 `knowledge-bank.json`。

**Q：LaTeX 公式不显示？**  
A：需联网加载 KaTeX CDN；公式写在 `data-tex` 属性中。

**Q：笔记会同步到手机吗？**  
A：交互笔记暂存本机。学习档案同步见第三节「同步数据」。

**Q：导入的 CSV 题其他电脑看不到？**  
A：导入存本机。导入后点「同步数据」，其他设备再点同步。

**Q：不规则动词为什么只有 47 个？**  
A：与教材 **附录5** 一致（不含情态动词）。见 `data/practice/irregular-verbs.json`。

**Q：如何安全批量更新精讲/题库？**  
A：使用 merge-by-id 脚本，勿整库覆盖。精讲：`python scripts/generate_u12_knowledge.py`（保留 `u3-k-part-b`）。补充包：`python scripts/build_practice_supplement.py`。
