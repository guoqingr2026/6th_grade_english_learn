第六步：全新知识点逐一精讲

🔑 知识点1：Did 疑问句三大规则

Did + subject + base verb?

📖 【新知识讲解】

规则一：Did 提前；规则二：Did 后动词用原形；规则三：答句用 did/didn't，不再重复实义动词过去式。

规则正确错误
Did 后用原形Did you eat mooncakes?Did you ate...? ❌
答句简洁Yes, we did.Yes, we ate. ❌
否定答No, we didn't.No, we don't. ❌

🏰 【记忆宫殿法】

红绿灯宫殿：绿灯 Did + 原形通过；红灯 ate/went 禁止进入 Did 后；黄灯答句只亮 did/didn't！

✍️ 【举一反三练习】

改错：
1. Did you ate mooncakes? → ___
2. Yes, I ate. (回答 Did you...) → ___
3. No, I don't. → ___

答案：
1. Did you eat mooncakes?
2. Yes, I did.
3. No, I didn't.

🔑 知识点2：规则 vs 不规则对照

clean→cleaned vs eat→ate

📖 【新知识讲解】

规则动词加 -ed；不规则动词单独背。节日主题高频对照表要熟记。

规则动词过去式不规则过去式
cleancleanedeatate

enjoyenjoyedmakemade
dressdressedwinwon

🔑 知识点3：三大句型综合

How was...? + What did...? + Did you...?

📖 【新知识讲解】

Unit 2 综合运用三种句型，完成节日主题对话：先问感受，再问活动，最后用 Did 确认细节。

句型例句用途
How was...?How was your holiday?问感受
What did...?What did you do?问活动
Did you...?Did you eat mooncakes?确认细节

🏰 【记忆宫殿法】

三层蛋糕宫殿：底层 How was（感受奶油）；中层 What did（活动夹心）；顶层 Did you（细节樱桃）！

✍️ 【举一反三练习】

完整对话编写（8 句）：
A: How was your ___ Festival?
B: It was ___!
A: What did you do?
B: We ___ and ___.
A: Did you ___?
B: Yes, we did. / No, we didn't.

课文填空与问答精讲

  1. Did + 主语 + 动词原形?
    一般过去时一般疑问句结构。
  2. ate / ran / made / won 分别是什么动词？
    eat / run / make / win 的过去式。
  3. cleaned / pasted / enjoyed 属于哪类变化？
    规则动词 + -ed。
  4. What did you like about it?
    I liked + 动词-ing / 名词。
  5. 综合：用 Did you...? 问 3 个节日活动
    Did you eat...? Did you watch...? Did you visit...?
  6. 翻译：我们贴了福字、穿了红衣服。
    We pasted fu and dressed in red.

语法巩固仿写 · Did 问句与答句

— Did you take a trip last holiday?
— No, we didn't. We stayed at home.
— What did you like about the book fair?
— I liked meeting the writer. It was fun!

得分要点：至少 1 组 Did 问答 + I liked... 句型。
