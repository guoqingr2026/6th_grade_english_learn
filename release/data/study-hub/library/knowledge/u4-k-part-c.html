课文填空与问答精讲

  1. want to do vs need to do
    want=想要；need=需要（更必要）。
  2. 填空：I want ___ (buy) some books.
    to buy — want to + 动词原形。
  3. 翻译：我打算等打折再买。
    I am going to wait for a sale.

语法仿写 · want / need / be going to

I want to buy a new pen. I need to save more money. I am going to write a spending plan this weekend.
