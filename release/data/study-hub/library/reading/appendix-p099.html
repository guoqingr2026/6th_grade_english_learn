共计 47 组动词及其过去式

不规则动词过去式变化规律分类归纳

第一类：原形与过去式完全相同（不变型）

  • cut → cut （切；割）
  • hurt → hurt （伤害）
  • let → let （让）
  • put → put （放）
  • read → read （阅读，发音变：/riːd/→/red/）

📌 记忆口诀：cut, hurt, let, put, read，原形过去一个样！

第二类：词尾变化型（加 -t 或 -ght）

  • bring → brought （带来）
  • buy → bought （买）
  • catch → caught （抓住）
  • feel → felt （感觉）
  • keep → kept （保持）
  • learn → learnt/learned （学习）
  • sleep → slept （睡觉）
  • teach → taught （教）
  • think → thought （思考）

📌 记忆口诀：-ght 和 -t 结尾，辅音悄悄变个样！

第三类：元音变化型（内部元音替换）

  • begin → began （开始）
  • drink → drank （喝）
  • drive → drove （开车）
  • eat → ate （吃）
  • find → found （找到）
  • fly → flew （飞）
  • get → got （得到）
  • give → gave （给）
  • know → knew （知道）
  • meet → met （遇见）
  • run → ran （跑）
  • see → saw （看见）
  • sell → sold （卖）
  • sing → sang （唱歌）
  • sit → sat （坐）
  • speak → spoke （说话）
  • stand → stood （站立）
  • swim → swam （游泳）
  • take → took （拿；取）
  • wake → woke （醒来）
  • wear → wore （穿；戴）
  • win → won （获胜）
  • write → wrote （写）

📌 记忆口诀：元音字母换一换，过去时态就出现！

第四类：完全不规则型（需单独记忆）

  • be (am/is/are) → was/were （是）
  • come → came （来）
  • do → did （做）
  • draw → drew （画）
  • go → went （去）
  • have/has → had （有）
  • hear → heard （听见）
  • make → made （做；制作）
  • say → said （说）
  • tell → told （告诉）

📌 记忆口诀：此类动词最顽固，一个一个死记住！
